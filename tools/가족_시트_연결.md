# 🍂 Gather family news in a Google Sheet (10 minutes, free)

If you leave `sheet` empty in `config.js`, letters, answers and hearts are saved **only on that phone**. (For previewing)
For the whole family to **see each other's letters and answers**, you use one Google Sheet as a "small server".
The sheet gets one tab for each kind of post. The tab names are in Korean:
`편지` (letters) · `질문 답` (answers) · `답장` (replies) · `하트` (hearts) · `출석` (visits) · `물 주기` (watering) · `투표` (votes) · `새 투표` (new polls) · `퀴즈 점수` (quiz scores) · `모습` (looks)

Menu names below are from Google's English interface. If your Google account shows Korean menus, see [Korean menu names](#korean-menu-names) at the end.

## 1. Make the sheet
1. Sign in to Google and type **sheets.new** in the address bar to make a new sheet.
2. Rename it at the top left to something like `Our family village`.

## 2. Paste the script
1. Click the menu **Extensions → Apps Script**. A code editor opens in a new tab.
2. Delete everything that's already there (`function myFunction() {}`), then paste in all of `tools/family-sheet.gs`.
3. 💡 You don't need to set the family password here. Once the connection is done, set it with **⚙️** on the village start screen.
   It's saved in this script and applies to the whole family. (If you don't set one, anyone with the link can come in.)
4. 💾 Save (Ctrl+S). Any project name is fine, e.g. `Family village`.

## 3. Deploy it as a web app
1. Top right: **Deploy → New deployment**.
2. The gear ⚙️ (Select type) → **Web app**.
3. Set these:
   - Description: `Family village v1`
   - **Execute as: Me**
   - **Who has access: Anyone** (it must be this, so the family can use it without signing in)
4. **Deploy** → **Authorize access** → pick your Google account
   → if a "Google hasn't verified this app" screen appears: **Advanced → Go to (project name) (unsafe)** → **Allow**
   (Google shows this only because it's a script you made yourself. It only touches this sheet.)
5. Copy the **Web app URL** shown on the screen (`https://script.google.com/macros/s/…/exec`).

## 4. Connect it to the village
In `config.js` (for the single-file version, inside `window.FAMILY = {` in `가족마을.html`):
```js
  sheet: 'https://script.google.com/macros/s/…/exec',   // the URL you copied in step 3
  site: 'kimfamily',                                    // the name that tells this family apart inside the sheet (English letters and numbers)
```
Then, before the real family uses it, **empty the sample data**:
```js
  samples: {},
```
(If you kept `window.FAMILY_EN`, empty `samples` there too.)

## 5. Check it
1. Open the village, create or pick your character, go in and send one letter → a row appears in the sheet's `kimfamily·편지` tab (letters).
2. Open it on another phone (or another browser). If you see the same letter, you're done!
3. (Optional, but recommended) On the start screen, **⚙️ → 🔒 Set password**. Now another phone asks for the password when it opens the village. A wrong one gets "Wrong password".
   ⚠️ If you put the village address on the internet, **set it on the day you connect.** With no password, anyone who knows the address can post, or set a password first.
   (If a stranger set one first, clear it as in "If you forget the password" below, then set your own.)

## Good to know
- **Tab names and header rows:** the script makes each tab and its header row by itself. Tabs are named `site·kind`, e.g. `kimfamily·편지`.
  The kind part and the header row stay in Korean, because the script finds existing tabs by these exact names. Don't rename the tabs, and leave the header row and the column order as they are; the script reads the columns by position.
- **Deleting a post:** delete its row in the sheet and it disappears from the village too. (Inappropriate posts, letters sent by mistake)
- **Changing or removing the password:** use ⚙️ in the village (or menu → Family password). Only someone who knows the current password can change it.
  Family members just enter the new password the next time they come in.
  **If you forget the password:** Apps Script → ⚙️ **Project Settings** → **Script Properties**, delete `FAMILY_CODE`, and the lock is off.
- **After changing the script**, do **Deploy → Manage deployments → ✏️ (Edit) → Version: New version → Deploy**, or the change won't take effect. The URL stays the same.
- **Time capsules:** before the opening day, the sheet doesn't send the letter's text out. (The sheet's owner can still read it in the sheet.)
- **If the connection drops,** posts are kept on the phone and sent to the sheet automatically the next time the village opens.
- **One sheet for several families:** give each one a different `site` and each gets its own tabs. (One password per script)
- Free limit: Google Apps Script is free up to thousands of requests a day, plenty for a family.
