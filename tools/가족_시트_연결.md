# 🍂 가족 소식을 구글 시트에 모으기 (10분, 무료)

`config.js`의 `sheet`를 비워 두면 편지·답·하트가 **그 휴대폰에만** 저장돼요. (미리보기용)
가족 모두가 **서로의 편지와 답을 보려면** 구글 시트 하나를 '작은 서버'로 씁니다.
시트에는 탭이 종류별로 생겨요: `편지 · 질문 답 · 답장 · 하트 · 출석 · 물 주기 · 투표 · 새 투표 · 퀴즈 점수 · 모습`

## 1. 시트 만들기
1. 구글에 로그인하고 주소창에 **sheets.new** 를 입력해 새 시트를 만들어요.
2. 왼쪽 위 제목을 `우리 가족 마을`처럼 바꿔요.

## 2. 스크립트 붙이기
1. 메뉴 **확장 프로그램 → Apps Script** 를 눌러요.
2. 원래 있던 글(`function myFunction() {}`)을 모두 지우고, `tools/family-sheet.gs` 내용을 통째로 붙여 넣어요.
3. 맨 위 줄의 **가족 암호**를 바꿔요. 가족끼리만 아는 숫자나 글자로요.
   ```js
   var FAMILY_CODE = '1234';   // ← 예: '0815', '김씨네최고'
   ```
   > 🔒 암호는 **여기에만** 적어요. `config.js`나 사이트 파일에는 적지 마세요. 사이트 파일은 주소만 알면 누구나 열 수 있어요.
4. 💾 저장 (Ctrl+S). 프로젝트 이름은 `가족 마을`처럼 아무거나 괜찮아요.

## 3. 웹 앱으로 배포하기
1. 오른쪽 위 **배포 → 새 배포** 를 눌러요.
2. 톱니바퀴 ⚙️ → **웹 앱** 을 골라요.
3. 이렇게 맞춰요:
   - 설명: `가족 마을 v1`
   - **다음 사용자 인증 정보로 실행: 나**
   - **액세스 권한이 있는 사용자: 모든 사용자** (가족이 로그인 없이 쓰려면 꼭 이것으로)
4. **배포** → **액세스 승인** → 내 구글 계정 선택
   → "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)(으)로 이동(안전하지 않음)** → **허용**
   (내가 만든 스크립트라서 나오는 안내예요. 이 시트에만 접근해요)
5. 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`) 을 복사해요.

## 4. 마을에 연결하기
`config.js`에서:
```js
  sheet: 'https://script.google.com/macros/s/…/exec',   // 3단계에서 복사한 주소
  site: 'kimfamily',                                    // 시트 안에서 이 가족을 구분하는 이름 (영어·숫자)
```
그리고 실제 가족이 쓰기 전에 **예시 데이터를 비워요**:
```js
  samples: {},
```
`lock.demoCode`는 시트를 연결하면 쓰이지 않아요. 비워도 돼요.

## 5. 확인하기
1. 마을을 열고 2단계에서 정한 **가족 암호**를 넣어요. 틀리면 "암호가 달라요"가 나와요.
2. 나를 고르고 들어가서 편지를 한 통 보내 봐요 → 시트의 `kimfamily·편지` 탭에 한 줄이 생겨요.
3. 다른 휴대폰(또는 다른 브라우저)에서 열어 같은 편지가 보이면 끝!

## 알아 두면 좋은 것
- **글 지우기**: 시트에서 그 행을 지우면 마을에서도 사라져요. (부적절한 글, 잘못 보낸 편지)
- **암호 바꾸기**: 스크립트의 `FAMILY_CODE`를 바꾸고 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포**.
  가족들은 다음에 들어올 때 새 암호를 넣으면 돼요. (주소는 그대로)
- **스크립트를 고친 뒤**에도 위처럼 '새 버전'으로 다시 배포해야 반영돼요.
- **타임캡슐**: 열리는 날 전에는 시트가 편지 내용을 내려보내지 않아요. (시트 주인은 시트에서 볼 수 있어요)
- **연결이 끊겨도** 쓴 글은 휴대폰에 보관됐다가, 다음에 들어올 때 자동으로 시트로 보내져요.
- **한 시트로 여러 가족**: `site`를 서로 다르게 적으면 탭이 따로 생겨요. (암호는 스크립트 하나에 하나)
- 무료 한도: 구글 Apps Script는 하루 수천 번 요청까지 무료라서 가족 규모에서는 걱정 없어요.
